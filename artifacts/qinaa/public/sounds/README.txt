# Sounds folder for قناع game narration

Drop your MP3 files here:

  sleep.mp3          — played at game start (everyone sleeps)
  mafia.mp3          — played when Mafia wakes
  investigator.mp3   — played when Investigator wakes
  protector.mp3      — played when Protector wakes
  day.mp3            — played when day begins

Only the host's device plays audio. Non-host players hear nothing.
