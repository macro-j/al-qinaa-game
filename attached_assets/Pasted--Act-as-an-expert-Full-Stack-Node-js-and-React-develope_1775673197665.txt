If actionType === 'protect' (from قناع الحارس), store targetId in protectTarget.

CRITICAL TASK 2: Morning Resolution Logic (Backend)
Create a function to resolve the night when the phase transitions to day_discussion:

Evaluate actions:

If killTarget exists AND killTarget !== protectTarget, find that player and set their state to isAlive: false.

If silenceTarget exists, add a property isSilenced: true to that player.

Clear the nightActions object for the next night.

Ensure all players' isSilenced flag is reset to false at the start of every new night.
